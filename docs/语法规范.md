# QXZ 语言规范 v1.0

QXZ 是**纯自主研发**的脚本语言：语法体系、中间表示（AST）与运行时均由 QXZ 自主设计实现，不基于、不继承任何既有语言。作为多语法前端，可解析 Java / Python / GO / PHP 等风格语法（解析能力，非语言依赖）。

> **文件后缀**：QXZ 源码文件后缀**通常为 `.qzm`**（用户确认，2026-09-23）。

## 1. 程序结构

QXZ 程序由一系列语句组成，语句以分号 `;` 结尾，代码块使用花括号 `{ }`。

```java
let x = 1;          // 语句
func foo() { ... }  // 函数定义
```

## 2. 语言声明头（Language Header）

文件第一行可用注释形式声明程序使用的语法与版本。QXZ 内置 Java 风格语法；运行其他语法（如 Python / GO / PHP）时需要 QZ 注册对应解析器模块。

**格式（严格）：**

```
//语法名 版本号
```

**规则：**
- 语法名与版本号之间**必须有一个或多个空格**，空格是分隔符，不可省略
- 语法名不能包含空格；版本号由数字和点组成
- 不符合该严格模式的行视为普通注释（如 `//Java17` 不会被识别为声明头）

**示例：**

```
//Java 17
let x = 1;
print(x);
```

```
//Python 3
print("hello")
```

当前 QXZ v1 已注册：`Java`（版本不限）。未注册语法会在运行时明确报错。

### 2.1 行级语言标记（用户确认，2026-09-25）

运行 **Java / C# / C++** 时，三者语法书写一致（同属 QXZ 统一语法体系）。这些代码的**对应行前端**必须添加语言类型与版本标记：

```
//(语言类型) (版本)
```

需要附加内容（如 JVM）时，在对应行前端增加：

```
//(语言类型) (语言类型版本) (附加内容) (附加内容版本号)
```

**示例：**

```
//Java 25
let x = 1;
//C++ 20
let y = 2;
//C# 12
let z = 3;
//Java 25 JVM 25
let w = 4;
```

**规则：**
- 标记中的语言类型、版本、附加内容、附加内容版本号之间**必须有一个或多个空格**，空格是分隔符，不可省略
- 语言类型 / 附加内容不能包含空格；版本号由数字和点组成
- 行首**仅 `//`**（无语言类型 / 版本 / 附加内容）时，作为**结束标记**：代表**指定语言执行完成本行之后结束**（✅用户确认，2026-09-25；区别于一般「不符合严格模式视为普通注释」的表述，此为显式结束标记）
- 此规则与 §2 上方「文件第一行声明头」并存；行级标记适用于 Java / C# / C++ 代码行（含 JVM 等附加环境场景）

## 3. 注释

| 语法 | 说明 |
|------|------|
| `// 注释` | 行注释 |
| `/* 注释 */` | 块注释 |
| `# 注释` | 行注释（兼容风格） |

## 4. 数据类型

| 类型 | 说明 | 示例 |
|------|------|------|
| int | 整数 | `42` |
| double | 浮点数 | `3.14` |
| string | 字符串（单双引号均可） | `"hello"` `'world'` |
| boolean | 布尔 | `true` `false` |
| null | 空值 | `null` |
| list | 列表 | `[1, 2, 3]` |
| 配置块 | section 块生成的字典 | `section app { ... }` |

## 5. 变量

使用 `let` 声明变量，类型由值推断：

```java
let x = 10;
let name = "QXZ";
let list = [1, 2, 3];
x = 20;              // 重新赋值
x += 5;              // 复合赋值（+= -= *= /=）
x++;                 // 自增
```

## 6. 运算符

| 类别 | 运算符 |
|------|--------|
| 算术 | `+` `-` `*` `/` `%` |
| 比较 | `==` `!=` `<` `<=` `>` `>=` |
| 逻辑 | `and` `or` `not` |
| 赋值 | `=` `+=` `-=` `*=` `/=` |
| 其他 | `++` `--` |

- `+` 可用于数字相加或字符串拼接
- `*` 支持字符串重复：`"abc" * 3` → `abcabcabc`
- 除法结果自动转为 double（`7 / 2` → `3.5`）

## 7. 控制流

### if / elif / else

```java
if (score >= 90) {
    print("优秀");
} elif (score >= 60) {
    print("及格");
} else {
    print("不及格");
}
```

### while

```java
let i = 0;
while (i < 10) {
    i++;
}
```

### for（类 C 三表达式）

```java
for (let i = 0; i < 10; i++) {
    print(i);
}
```

支持 `break` 跳出循环、`continue` 跳过本次迭代。

## 8. 函数

```java
func add(a, b) {
    return a + b;
}

let result = add(3, 4);   // 7
```

函数支持递归、闭包（可捕获外层变量）。

## 9. section 块（QXZ 特色语法）

`section` 是 QXZ 独有的结构化配置/数据描述语法，用于定义命名配置块，值可以是任意表达式：

```java
section server_config {
    host: "127.0.0.1";
    port: 8080;
    debug: false;
    modules: ["http", "db"];
}

print(server_config["host"]);   // 通过下标访问
```

## 10. UI 声明块（QXZ 特色语法，QZ UI 引擎）

`ui` 块用于声明式描述游戏/应用界面，由 QZ UI 布局引擎解析为渲染指令（布局模型依据 EXCOYZNVM 设计稿归纳的多区布局设计：row/column 流式盒模型 + 固定/fill/wrap 尺寸 + gap/padding/align/justify）。

```java
ui main_screen {
    direction: "row";            // 根属性：布局方向（row/column），默认 column
    width: "fill";               // fill 占满 / wrap 自适应 / 固定像素
    height: "fill";
    bg: "#FFFFFF";               // 支持各种颜色：#RGB / #RRGGBB / #RRGGBBAA / 命名色

    panel left_menu {            // 节点：类型名 节点名 { ... }
        width: 180;
        direction: "column";
        gap: 4;
        padding: 8;
        border: 1;               // 边框宽度
        border_color: "#CCCCCC";
        bg: "#F5F5F5";

        text app_title { value: "EXCOYZNVM"; bold: true; font_size: 18; color: "#333333"; }
        button about { label: "关于"; bg: "#FFFFFF"; color: "#000000"; border: 1; }
        divider div1 { }
        button exit { label: "△ 退出"; bg: "#FFE4E1"; color: "#CC0000"; }
    }

    panel account_area {
        width: "fill";
        direction: "column";
        align: "stretch";        // 交叉轴对齐：stretch / start / center / end
        justify: "start";        // 主轴对齐：start / center / end
        text greeting { value: "欢迎回来"; color: "#1E88E5"; font_size: 20; bold: true; }
    }
}
```

**节点类型**：`panel`（容器）/ `button`（按钮，label 文本居中）/ `text` / `icon`（icon+icon_size）/ `image` / `input`（hint 占位）/ `divider`（分割线）/ `spacer`（占位填充）。

**尺寸语义**：
- 数值 → 固定像素；`"fill"` → 占满主轴剩余空间（显式声明才均分）；缺省/`"wrap"` → 按内容自适应
- 根节点未显式指定宽高时，默认画布 1094×547（对齐设计稿横屏规格）

**样式属性（支持各种颜色值）**：`bg` / `color` / `border` / `border_color` / `radius`、`padding` / `margin` / `gap`、`width` / `height`、`direction` / `align` / `justify`、`font_size` / `bold` / `text`(或 value/label)。

**运行行为**：ui 块注册为同名屏幕并立即布局渲染；可用 `uiShow("屏幕名")` 切换显示（见 §11 标准库）。

## 11. 标准库

| 函数 | 说明 |
|------|------|
| `print(...)` | 输出，多参数用空格分隔 |
| `input()` | 读取一行输入 |

## 11. 与 Java 的差异（设计说明）

- **无强制类型声明**：变量用 `let` 声明，类型动态推断（类似 var）
- **无类/对象体系**（v1 暂定）：以函数和数据结构为核心，简化语言模型
- **无异常体系**（v1 暂定）：错误以运行时消息形式报告
- **无 import/包管理**（v1 暂定）：单文件脚本，后续版本规划
- **新增 section 语法**：配置描述一体化
- **新增 ui 语法**：声明式 UI 布局（由 QZ UI 引擎渲染，安卓壳等平台经 UiHost 桥接绘制）
- **新增 `#` 注释**：兼容脚本语言习惯
- **逻辑运算符用英文单词**：`and` / `or` / `not`（同时词法层支持 `&&` / `||` 自动映射）
- **语言声明头**：第一行 `//语法名 版本号` 指定解析器，空格不可省略

## 12. 运行方式

QXZ 程序由 QZ 运行时执行：

```bash
java -cp build qxz.Main run program.qxz
```

运行流程：源代码 → 语言声明头识别 → 词法分析（Lexer）→ 语法分析（Parser，生成 AST）→ QZ 解释执行（Interpreter）。

## 附：支持平台（最低要求）

QXZ 运行于以下平台（均为 64 位，对应耀菱生态平台级最低运行环境）：

- **操作系统**：Android 6+ / 鸿蒙 HarmonyOS 5+ / Windows 7+ / Ubuntu 18+ / Meta 头显
- **图形后端**：DX11+ / OpenGL 4+ / 渲染龙（RenderDragon）/ Vulkan 1.1+
- **最低硬件**：2GB RAM / 5GB ROM / 1.5GHz 四核 CPU
